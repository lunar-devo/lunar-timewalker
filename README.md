# LUNAR TIMEWALKER — A Moon and Sky Observation App That Runs in the Browser

**Lunar Timewalker**, built for the **NASA Space Apps Challenge 2026 (Sakarya)**, is an interactive Moon, Mars and sky exhibit that runs in the browser: teachers can show it in class and anyone can explore it freely. You walk on real **NASA LRO/LOLA** (Moon) and **MGS/MOLA** (Mars) terrain data and watch real sky events between 3000 BC and AD 2035 in the order **before → event → after**. The positions of celestial bodies come from an ephemeris engine verified against **JPL Horizons DE441**.

**Live demo:** https://lunar-devo.github.io/ · **Source code:** https://github.com/lunar-devo/lunar-timewalker

---

## 1. Quick Setup and Running

### Requirements
- **Node.js** `>= 22` and `npm`; a desktop browser with WebGL2, or a touch-screen tablet / interactive whiteboard (not designed for phone screens).
- *(Optional — to reprocess the raw NASA datasets)* **Python 3.11+** and `uv`. The processed textures, LOLA elevation data, GLB models and catalogues are ready under `public/assets/`.

```bash
npm install
npm run dev        # http://localhost:5173
npm run typecheck
npm test           # ephemeris (JPL Horizons), staging, Explosion Lab model and translation coverage tests
npm run build
```

**Publishing:** `npm run deploy` builds the app and sends the build as a single commit to the site repository (`lunar-devo/lunar-devo.github.io`, the remote named `site` in git) (`tools/deploy_pages.sh`); GitHub Pages publishes that repository at the root of the domain. The build uses relative paths (`vite.config.ts`: `base: './'`), so the `dist/` folder can be served from any server, from the root or from a subdirectory.

Rebuilding the asset bundle from the raw NASA sources (all of it or selected steps):
```bash
uv run tools/build_assets.py                 # all
uv run tools/build_assets.py dems stars      # DEMs and star map only
uv run tools/build_assets.py mars_dem        # Mars global elevation map (MGS MOLA, 16 pixels/degree)
uv run tools/build_assets.py planets galaxies # planet maps and galaxy images (the galaxies step downloads the 4 GB 64K star map)
uv run tools/measure_galaxies.py             # centre, place on the sky, width and rotation of each galaxy image (written into src/content/galaxies.ts)
```

When interface text is added or changed, the translation dictionaries are updated (requires `bun`):
```bash
bun tools/i18n.ts scan      # is any text written in a form that cannot be translated?
bun tools/i18n.ts extract   # tools/i18n/todo.<lang>.json: texts missing a translation
bun tools/i18n.ts merge     # tools/i18n/done/<lang>.NN.json → public/assets/i18n/<lang>.json
```

**Optional NASA API key:** while online, the DONKI records of the May 2024 storm are also queried from `api.nasa.gov`. If no key is given, NASA’s public `DEMO_KEY` is used; if its limit is exceeded or there is no connection, the archived copy shipped with the app is shown and the screen says so. You can give your own key with the `VITE_NASA_API_KEY` environment variable; this value is embedded in the built files and anyone who opens the site can read it, so only use a key you do not mind sharing.

## 2. How It Is Used

1. **Home menu:** 12 events (with a category filter), **7 Galaxies** (Andromeda M31, Triangulum M33, Whirlpool M51, Sombrero M104, M87, the Large and Small Magellanic Clouds), **9 Planets/Worlds** (Moon, Mercury, Venus, Earth, Mars, Jupiter, Saturn, Uranus, Neptune) and four entries: **Tutorial**, **Free Exploration**, **Explosion Lab**, **Spectator Mode**; plus settings, controls and data sources. The Explosion Lab is entered from the home menu or through a shared scenario link; while an explosion from the lab is being watched from a surface, the **← Back to the lab** button returns to the lab.
   **Button layout.** The top bar on the surface, from left to right: *where you are* (← Home menu · planet · place `[M]`), compass, *what you look with* (Telescope `[T]`, Sky guide `[C]`), *what you read* (Data `[N]`, Archive `[I]`), and at the far right `⋯` (view, lamp, sound, clean view, photo, controls, language). The close-up of an event is opened with the **Close-up →** button on the event card on the left (or by clicking the body in the sky). The close-up bar holds back, going to that planet with the astronaut, Archive, Sound, Clean view and language.
   **Archive `[I]` opens the subject of the page you are on:** in a galaxy view the NASA images of that galaxy, in a planet view of that planet, in an event of the event, in the lab of the selected explosion type (most are photographs, some are computer simulations; the source of each is written under it); the subject looked at on the previous page is not carried over. The images of a particular spacecraft or body open with the **Open NASA images** button on its own card. **Returning to the home menu closes the session:** everything opened from the menu (planet and galaxy views, the lab, walking on a planet) starts with today’s date and independent of the previous event, and `Esc` returns to the home menu. When the page changes, open cards, panels, subtitles and narration close.
2. **Moon map (`[M]`):** Choosing a location; on the surface the place can be changed at any time with `[M]`. For each event the best place, where the target stays above the horizon, is suggested automatically; the selected place scrolls itself into view in the list, and a custom point picked on the globe also has day/night, Earth and target badges. The **Clock** next to the title is the time the clock shows at that moment: for staged events it is the start of the “before” scene; the date of the event is written on its card. **Free Exploration opens with today’s date** and the first place in the list that sees the Sun at that moment is selected (so as not to start in the dark). The **Watch from** list at the top chooses from which planet the event is watched (item 4 below).
3. **Before → Event → After:** When you go to the chosen place, the event’s staging plays: first the sky/surface *before* the event, then the event itself (sped up if needed), then what follows. The step and a description appear on the strip at the top. **The BEFORE / EVENT / AFTER labels are buttons:** playback starts from the part you click; when the staging ends, the same three buttons stay at the top as a small row. **Skip** passes it, `[R]` / **Replay** plays it again from the start (even when time is paused). **The three events that do not take place in the Moon’s sky open in their own view, without choosing a place on the Moon:** the 2018 Mars dust storm (Mars globe), the May 2024 solar storm (Sun view) and the 2003 close approach of Mars (**orbit cinematic**: the orbits of the Sun, Earth and Mars from above; Earth catching up with Mars and passing between the Sun and Mars, the distance line between them, the light travel time and the size of Mars in the telescope, as live numbers).
   **A mission on Mars: Ingenuity’s first flight (19 April 2021).** Like Apollo 11 on the Moon, it is watched from the surface: at the Wright Brothers Field in Jezero the helicopter spins up its rotors, climbs to 3 metres, hovers for 30 seconds while turning 96° and lands (39.1 seconds in the air; NASA release 21-039). The flight plays in real time; Perseverance watches from 64 metres away. Because the flight takes place on Mars, it is watched only from Mars.
4. **Moving according to each planet, and watching events from other planets:** From the top bar, the map or the menu you can choose the **Moon** (`1.62 m/s²`), **Mercury**, **Venus**, **Earth** (`9.81 m/s²`, blue sky), **Mars** (`3.72 m/s²`, thin atmosphere; real Martian terrain) or the gas/ice giants (no solid surface — flight above the clouds in zero gravity with `WASD + Space/Q`). Sky events (supernovae, comet, conjunction, alignment) can be watched from the chosen planet: the sky is computed for that planet, and an observing spot where the target is above the horizon and, if possible, in the dark is chosen automatically. Because the planets spin quickly, the sky is **held to the stars** during the staging (one frame per rotation of the planet); this, and (except on Mars) that the ground is a model, is written on the screen. Events that take place on the Moon (Apollo 11, the 2026 eclipse seen from the Moon, the Shackleton sunrise) are watched only from the Moon. You can look around **by dragging the screen** without needing a mouse lock (`[Tab]` turns on the optional mouse lock).
   The chosen planet stays: on a planet, picking another place on the map with `[M]` does not take you back to the Moon (the **World** list in the map title shows the planet you are on); when an event that takes place on or is watched from the Moon is chosen, the map opens again with the Moon, and for an event on Mars with Mars. In Free Exploration, going to another planet chooses an observing spot on the **day** side automatically: on Mercury, Venus and Earth the Sun is about 38° high; on the gas/ice giants it is a low Sun (≈16°) that shows the relief of the cloud tops; on Mars you land at the first mission site that sees the Sun at that moment (at Jezero if none is in daylight).
   **Mars is a real place.** When Mars is chosen (the Mars card in the menu, the planet list in the top bar, the list on the map or a Mars event), the map opens with the **Mars globe** and lists four mission sites: **Jezero Crater** (Perseverance and Ingenuity), **Chryse Planitia** (Viking 1), **Utopia Planitia** (Viking 2), **Elysium Planitia** (InSight). The ground is built from NASA’s MOLA elevation data, the sky is the Martian sky for that latitude, longitude and date, the spacecraft stand on the ground as NASA’s 3D models, and `[E]` opens their info cards. You can also click any point on the globe and land there (for example the summit of Olympus Mons or the Hellas basin). Curiosity, Spirit, Opportunity, Phoenix and Pathfinder have no landing site because NASA has no open 3D model of them; they appear as pins on the Mars globe.
   The time bar at the bottom has a **Now** button next to the day/hour steps, the year slider and the speed buttons: it sets the clock to the device’s current time, so the sky is shown as it looks from the Moon (or the chosen planet) **right now**.
5. **Explosion Lab:** You choose a Type II / Type Ia supernova, a gamma-ray burst or a solar eruption (CME); the explosion’s distance from Earth is set from the Moon’s distance up to 10,000 light years, and **Detonate** starts it. First the light, then the shock wave (or plasma cloud) sweeps across the **Sun-centred map** and reaches each body in the order of its real distance. On Earth: depending on the distance, Earth is lit up, the side facing the explosion is scorched, the ozone layer is torn, the atmosphere is blown into space, the oceans boil, the crust melts, the planet is shattered and its remains are pushed away (its first position stays marked on the map); in a CME the magnetosphere is compressed, the aurorae move down towards the equator, and only in storms stronger than May 2024 do the city lights (power grids) go out. The panel on the right shows the numbers (brightness, arrival times, temperature, energy, push speed), damage bars and the order of events. The display is sped up: **the order and the times written are real, the speed of the display is not**. If you like, you can fly inside it with the 0g astronaut.
   **Not only Earth: every body on the map is affected.** The Moon, the Sun and each of the seven planets respond to the explosion from their own place: the light and the shock wave reach each one according to its own distance; it is lit up, the side facing the explosion is scorched, its atmosphere is blown away like a tail, its crust melts, it is shattered or (gas and ice giants, the Sun) loses its upper layers, and is then pushed away (Venus loses its cloud cover, Saturn its rings). The **What happens, in order** list on the right orders all the bodies on the map by their real distance from the explosion: each row gives the real time elapsed after the explosion and the body’s fate (“75 min · Earth: destroyed”, “5.3 hours · Sun: loses gas from its outer layers”, “22 hours · Jupiter: upper layers torn off”); a row lights up when the wave reaches the body, clicking a row goes to that body, and unaffected bodies are listed faintly at the end. The whole map is tied to a single clock, and the light and shock fronts drawn are the real fronts passed through the map’s projection: a body’s effects begin at the moment the front touches its symbol (which is why the front of a distant explosion looks like a curved line on the map). Earth’s card also counts the other bodies destroyed together with Earth. The ring around each body has the colour of its outcome (green harmless, yellow caution, orange dangerous, red devastating). In a CME the cloud is a cone about 70° wide aimed from the Sun at Earth: it hits the bodies inside it (on planets with a magnetic field the magnetosphere is compressed and aurorae glow; on Venus and Mars gas escape from the upper atmosphere speeds up; on the Moon and Mercury it reaches the surface) and misses those outside — which planet is hit depends on the real arrangement on the map’s date. In the **Bodies affected** list at the top right, clicking a name takes the camera to that body and opens the result card for it (distance from the explosion, brightness compared with the Sun there, arrival times, temperature, energy received, damage bars, order of events); **×** removes the Moon or a planet from the map, **+** puts it back (Earth and the Sun cannot be removed, because the explosion’s distance is measured from Earth and the Sun is the centre of the map). A removed body is also dropped from the place options.
   **The map is Sun-centred.** The Sun is in the middle; the planets from Mercury to Neptune sit in their real order on their own orbits, at their **real longitudes** around the Sun on the map’s date (**today** when opened from the menu) (`astronomy-engine`); the map is seen from the north, and as the date advances the planets turn anticlockwise. The distance scale is schematic: the mean distances of successive planets are equally spaced rings (distances between them are placed logarithmically), and beyond Pluto there is a single logarithmic scale up to 10,000 light years. Earth’s near surroundings are enlarged: the Moon and an explosion as close as the Moon appear separate from Earth. The projection can be inverted: every point on the map corresponds to a single real place, and the distance from Earth of an explosion placed at the clicked point is computed from it. The planets are drawn with their real maps, Saturn with its rings; on the distant rings Alpha Centauri, Sirius, Betelgeuse and the Crab Nebula are in their real directions; the background is the real star map turned to the ecliptic. The bodies are not to scale (they are drawn at least a few pixels across). The place of the explosion is chosen with the slider, with the body names on the left, or **by clicking a body on the map / its name / an empty spot** (when a body is chosen the explosion is placed beside it; when a star is chosen that star itself explodes). Names are not written over each other or over bodies.
   **Results say where they come from on the screen:** under the “Effect on …” title there is the line *MODEL — This app’s own estimate, not a statement by NASA.*, and at the end of the panel the section **What is the estimate based on?** (the 26 light-year limit from NASA research, the May 2024 measurement, the model’s own assumptions, how the other bodies are computed, the source of the planet positions and images). The “HARMLESS / CAUTION / DANGEROUS / DEVASTATING” labels and the wording of the results belong to the app.
   When the lab opens, the camera fits **the whole planetary system** between the two panels with the Sun in the middle. The **Whole orbit / Whole map / Close to the chosen body** buttons at the bottom change the view; dragging rotates it, and the wheel zooms out far enough to take in the whole map. After detonating, the wide view stays: you watch the wave sweep through the system and the bodies being affected in turn; the close-up of a body opens with **Close to the chosen body** or by clicking the body’s name. In the close-up, the debris of bodies larger than the chosen body is not drawn: since the bodies are not to scale relative to each other, a large body’s debris would cover its small neighbour. Ring names sit on the side of the ring that faces the camera and move out of the way of bodies.
   **The lab’s tools.** In a *gamma-ray burst* the ten-second burst of radiation travels in two narrow beams: bodies inside a beam are affected, those outside see nothing; the danger limit at 6,500 light years is a red ring on the map. *The strength of the solar eruption* has three levels: ordinary, May 2024, Carrington class (1859). *The date of the map* can be changed (1900–2100): the planets move to their positions on that day, and an explosion placed beside a body moves with that body; which planets the CME cloud hits changes with the date. After detonation, the bar at the bottom **pauses the display and scrubs it back and forth**. **Show all in a table** puts the numbers of all the bodies side by side. **+** adds **Pluto, Titan and Europa** to the map (ice crusts melt long before rock; in an ordinary solar eruption Titan stays inside Saturn’s magnetosphere, in a strong one it is exposed to the solar wind). In a solar eruption **satellites** are drawn around Earth (L1 watchers, geostationary ring, GPS, Space Station): whether they stay inside or outside the magnetosphere, and the warning time L1 gives, are written on a separate card. **Copy link** gives the scenario as an address (`?lab=…`); whoever opens the link sees the same explosion. **Predict: 5 questions** is the class mode: first the outcome is predicted (the rings and the result card are hidden), then the explosion is watched and compared with the model’s result; the correct answer is not written into the question, it is the result the model gives at that moment. For supernovae, **Watch from there** lets you watch the explosion from the surface of the chosen world (of the Moon if you cannot stand on it), as a new star in the sky; **← Back to the lab** brings you back to the same scenario.
   **The end of the display and choosing a place.** When the sped-up display reaches its end it stops and holds the last frame; `↺` at the bottom plays it again from the start, and the slider scrubs back. After the display has started, clicking the map does not change the place of the explosion (so that a wrong touch on a touch board does not wipe the scene): first press **Reset**. An explosion placed “beside that body” by clicking a body or with the place button counts as right beside that body (three radii away, inside the gamma-ray beam) whatever the date on the map. A body’s name is hidden if there is no free space around it; an explosion placed at a star or nebula appears, when watched from a surface, at that star’s real place in the sky.
6. **Clicking a body in the sky, Telescope (`[T]`), Sky guide (`[C]`), Clean view (`[U]`):** On the surface, **clicking a body in the sky, its dot or its name** opens its close-up (Moon and planet globes, the Sun and CMEs, the supernova remnant, galaxies); for bodies without a close-up (the comet) the camera turns to it, and for spacecraft on the surface an info card opens. The compass at the top and the names under **Look at** turn the camera to the body. `[T]` opens the telescope; `[C]` turns on constellation lines, the ecliptic arc and bright star names; `[U]` hides all panels for projection in class (in the Explosion Lab too: the map takes the whole screen; the **Show controls [U]** button at the bottom right brings the panels back).
   **The galaxy close-up** opens with the **real image** of the galaxy. For Andromeda and the two Magellanic Clouds, the **“In which light?”** button on the card switches the image: **visible light** (Andromeda: Hubble’s 2025 mosaic; Magellanic Clouds: a cut-out from NASA’s 64K star map — a drawing of the individual stars in the Gaia catalogue, not a photograph) and **ultraviolet** (GALEX) or **infrared** (Spitzer). M33 is a GALEX ultraviolet image; M51, M104 and M87 are Hubble images. The ultraviolet and infrared images are *false colour*; the card states the image’s type and source. When dragged, the image turns into particles taken from its own pixels and gains depth: the spiral galaxies and the Large Magellanic Cloud become a tilted disc with their published inclinations, long axes and near sides, the bulging body of M87 and the Sombrero a ball, the Small Magellanic Cloud a thick cloud (M32 beside Andromeda stays a separate ball). This depth is a **model** (the image holds no depth information); a double click returns to the real image. The same images also sit in the sky: each at its **measured** place, width and rotation (by matching against north-up survey images from NASA SkyView; `tools/measure_galaxies.py`). Small galaxies are enlarged so that they can be found in the wide view and shrink to their real size in the telescope; in the wide view the Magellanic Clouds are part of the star map itself, and in the telescope the sharp cut-out takes over.
   **Scale:** Under the galaxy there is a **scale bar** showing a round number of light years at the galaxy’s distance (it updates as you zoom in and out); if the image is wide enough, the **full Moon at the same scale** is drawn beside it (Andromeda’s Hubble mosaic is 4.5 full Moons wide side by side in the sky). The card gives the image’s width on the sky (in degrees and in full Moons) and how many light years that is at that distance; these numbers are computed from the image’s **measured** width and the galaxy’s distance (in the M87 image the 5,000 light-year bar agrees with the known length of the jet).
7. **7 languages:** Turkish, English, German, French, Spanish, Italian, Russian. The site **opens in English**; the language is changed from the menu, the settings, the `⋯` menu on the surface and the close-up bar, and the choice is remembered. 4K and 8K photos (`[P]` = 8K, 7680×4320). In narrow windows (1024 pixels) the top bar on the surface moves the buttons that do not fit into the `⋯` menu; the time bar and the close-up bar keep the bare minimum and hide the rest. There is no mission chain and no certificate; the only scored activity is the five-question prediction activity in the Explosion Lab.
8. **Sound:** Generated entirely in the browser; no recordings are used. In the menu and the space views a quiet background music of slowly changing chords and sparse bell sounds plays; on the surface the sounds carried by the suit (airflow, breathing, boot impacts) come forward and the music stays in the background. Space is silent: the music is like a film score, not something the astronaut hears. **Sound can be turned on and off:** the `[K]` key, the **Sound: on / off** button in the home menu, the `⋯` menu on the surface, the **Sound [K]** button in the close-up and lab bars, or the checkbox in the settings; the choice is remembered. The volume is changed in the settings.
9. **Touch screen (tablet, interactive whiteboard):** Drag with one finger to look around or rotate the globe, pinch with two fingers to zoom, tap to select. On the surface, at the first touch, direction keys and **Jump** (in zero gravity **Rise / Descend**) appear on the screen; they disappear when a key is pressed on the keyboard. Not designed for phone screens.
10. **Keyboard and windows:** Every window that opens (settings, controls, sources, cards, archive, lab table) takes keyboard focus, `Tab` moves within it, `Esc` closes it and focus returns to the button that opened it. While a window is open, the surface keys (walking, telescope, photo…) do not work. A button, slider or list used with the mouse gives the keyboard back to the scene; `Esc` also returns from the map. The second click of a double click does not press anything on the new page that opens.

### Tutorial and Spectator modes
- **Tutorial:** 13 steps at the Apollo 11 landing site (looking, walking, running, jumping, 3rd/1st person, covering the Sun with your hand, getting information with `[E]`, telescope, zooming in on Earth, entering the Earth view and coming back, speeding up time). Each step shows its keys and moves on by itself when done; there are **Skip** / **Exit** buttons.
- **Spectator Mode:** Shows the 12 events in order, hands-free, for teachers to play in class; after each event it waits 6 seconds and moves to the next (Mars and Sun events play in their own close-ups). Controls: `←`/`→` previous/next event, `Space` pause, `Esc` menu. The interface is simplified.
### Visual detail
- Star map, constellation lines, Moon colour, Mercury, Mars, Earth (day, night lights, monthly and dated images) at **8K** (8192×4096) — produced only from data whose source is at least 8192 pixels. The Moon relief normal map is 4K, because the source LOLA data is 16 pixels/degree (5760×2880).
- Planet globes from real maps: Mercury MESSENGER colour mosaic, Jupiter / Saturn / Uranus Hubble OPAL maps (Jupiter 2024, source 3600 pixels wide; Saturn 2025: because the rings are seen edge-on, **both hemispheres were observed** (79° N – 85° S), and only the equatorial strip covered by the rings (0.3°–4.9° N) is filled in from both sides; Uranus 2015: colour by latitude, observed between 88° N and 49° S, there is no Hubble data further south and the last observed colour is extended), Neptune the NASA 3D Resources texture (720 pixels). There is no map of Venus’s cloud tops; its globe is a model. Saturn’s rings are at their real radii (C, B, Cassini Division, A, Encke Gap); the rings cast shadows on the globe and the globe on the rings. The close-up shows the whole globe, from its day side.
- The **cloud tops** on the gas and ice giants, where you fly instead of walking (belts, vortices, relief, horizon haze), are a model; they are not the image of a real place.
- Earth: where a satellite image exists for that date (2000-05-05, 2003-08-27, 2018-06-20, 2024-05-10, 2026-08-12) **the real clouds of that day** (NASA GIBS, MODIS Terra / VIIRS SNPP); on other dates the cloud-free Blue Marble composite of the same month. City lights are absent before 1880 and grow until 1990 (approximate model).
- Lens flare for the Sun (off in the telescope, follows the “Reduce flashes” setting), in-helmet vignette/chromatic aberration, round dust particles, LOLA-relief lighting on the Moon globe.
- Astronaut: when running (`Shift`) the elbows bend, the arms swing opposite to the legs and the body leans slightly forward; the arms rise only on a deliberate jump (or in 0g). Because the trouser legs are split by surface part, no tear shows on the inner leg in a long stride.
- 4K/8K photos are rendered in 1920×1080 tiles with margins and stitched together; so they need no more graphics memory than normal play.
- **Frame-rate guard:** If frames start to lag (below 56 per second for 1.5 seconds), the drawing resolution is lowered step by step; once the rate holds for a while, one step back up is tried, undone if it is too much, and not tried again in that scene. If lowering the resolution does not speed up the frames (a browser in power saving, a 50 Hz display, a CPU bottleneck), the step is undone at once. The resolution of the quality level in the settings is never exceeded; the current drawing resolution is shown in Settings (`src/game/resolution.ts`, tests `resolution.test.ts`). Measurement (Apple M5, 1920×1080 window, 2× display, “High”): the Moon surface runs at 38 frames/s at 3840×2160; the guard brings it down to 2715×1527 and it rises to 60 frames/s.

## 3. What was measured, what was modelled?

| Item | Status |
| --- | --- |
| Positions of the Sun, Earth and planets | **Computed**: `astronomy-engine`; tested against JPL Horizons DE441 tables (`npm test`). |
| Lunar terrain (general) | **Measured**: LOLA global DEM, SVS #4720 `ldem_16` (≈1.9 km/pixel). |
| Martian terrain | **Measured**: MGS MOLA global elevation map (MEGDR, 16 pixels/degree ≈ 3.7 km/pixel), metres relative to the areoid. Craters and rocks below this resolution are a **statistical model**, as on the Moon; the ground colour is sampled from the Viking colour mosaic. |
| Ingenuity’s flight | **Record**: take-off time, 3 m height, 30 s hover, 96° turn, 39.1 s duration (NASA 21-039). **Reconstruction**: the path between the recorded points, the climb and descent rates, Perseverance’s direction relative to the helicopter. |
| Shackleton rim and Connecting Ridge | **Measured**: PGDA LOLA 5 m/pixel (`Site04`, `Site01`). |
| Craters and rocks below DEM resolution | **Statistical model** (not real; the same function on CPU and GPU). |
| Apollo 11 times | **Historical**: touchdown 20:17:40 UT, lift-off 17:54:00 UT, equipment set-up times. The landing/lift-off trajectory is a simple curve fitted to the crew’s calls. |
| Supernova light curves | **Template model** (Type Ia / Type II), fitted to historical peak brightnesses. |
| 44 BC outburst | **Literature model**. |

The thresholds are derived from the body’s own values: energy to lift the atmosphere GM/R, for rocky bodies the same crust column as on Earth, for the giants and the Sun the outermost thousandth of the mass, for dispersal 3GM²/5R; brightness is compared with the sunlight the body normally receives, and temperature is scaled by (1+f)^¼. The CME cloud is taken as a cone 70° wide (the width of real CMEs varies); its pressure falls with the square of distance and is compared with the ordinary solar wind at the body’s position, and magnetospheres are compressed with the −1/6th power of the pressure ratio. That Mars loses gas to space faster during solar storms is **measured** (MAVEN, NASA release 15-217); the model has no amount for it. On the map, the planets’ **place around the Sun is computed** (for the map’s date); orbit spacings are schematic, beyond Pluto is logarithmic, Earth’s near surroundings are enlarged, the bodies are not to scale; the distance the bodies are pushed and the size of the debris are for display only. **It is not a prediction.** |
| Explosion Lab — labels of the other bodies and display time | For bodies other than Earth, “HARMLESS / CAUTION / DANGEROUS / DEVASTATING” measures physical loss, not life: devastating = shattering, melting or stripping of the atmosphere / upper layers; dangerous = these happening partly, or the explosion appearing brighter than 10 times the sunlight there; caution = appearing brighter than one twentieth of the sunlight there. A body counts as shattered when the energy received reaches the binding energy; the summary, the order of events and the image use the same threshold. The sped-up display uses one clock for the whole map: the light and shock fronts reach each body **in the real order of arrival**, and the fronts drawn are the real fronts passed through the map’s projection; the speed of the display is not real (the first shock arrival is held for 1.8 seconds so that the light’s steps can be seen), and the real times are written in the list and the panel. The map’s projection (equally spaced orbit rings, the enlargement around Earth) is schematic and is in `src/views/lab/map.ts`. |
| Explosion Lab — gamma-ray burst, storm strength, satellites, added bodies | **Gamma-ray burst**: the burst in the study by Thomas et al. The ordinary eruption is taken as 5 nPa and 3.5 days. **Satellites**: the orbit heights are real (Space Station 420 km, GPS 20,200 km, geostationary 35,786 km, L1 1.5 million km); whether they stay inside / at the edge of / outside the magnetosphere is computed from the model’s magnetopause distance, and the L1 warning time from the cloud’s speed. **Added bodies**: Pluto, Titan and Europa are treated as icy bodies (threshold for melting a 20 km ice crust); the moons are taken at their planets’ position and are shielded from the solar wind until the planet’s bow shock moves inside their orbits. That Titan was observed outside Saturn’s magnetosphere in December 2013 is **measured** (Cassini, NASA JPL 28 January 2015). **Watching from the surface**: the star’s direction, distance and peak brightness come from the lab scenario; the light curve is a general template; the lighting of the ground by a very bright supernova is computed relative to the Sun and capped at 2.5 Suns. |
| Planet maps | **Measured**: Mercury (MESSENGER MDIS), Jupiter (Hubble OPAL 2024), Saturn (OPAL 2025; both hemispheres observed, the median colour of each latitude with the observed detail on top), Mars, Moon, Earth. **Partly measured**: Uranus (OPAL 2015; colour profile by latitude, south of 49° S not observed). | Galaxies | The images are **measured** (Hubble, GALEX, Spitzer; the ultraviolet and infrared ones are false colour). The place on the sky, width and rotation are **measured**: each image is matched to a north-up survey image from NASA SkyView (M87 by its jet, Andromeda’s Hubble mosaic by the core and M32; none is a mirror image); the long axes measured in the images agree with the published position angles to within a few degrees. The **3D depth** given to the image is a **model**: for discs the published inclination, long axis and near side are used (the north-west of Andromeda, the north-east of the Large Magellanic Cloud and the south of the Sombrero are published; the west of M33 and the east of M51 are inferred from the direction of rotation and the winding of the arms); for balls a modified Hubble profile is assumed. |

During staging the observing spot is held to the stars: what is shown is single frames taken once per rotation of the planet. |

## 5. Texts for the Submission Form

### A. Short Summary
- *Lunar Timewalker is a browser-based Moon, Mars and sky exhibit for teachers and students: walk on real NASA LOLA (Moon) and MOLA (Mars) terrain and watch historic events in order — before, during and after: Eagle landing at Tranquility Base, Ingenuity’s first flight in Jezero Crater, the 1054 and 1006 supernovae, Jupiter and Saturn converging in 7 BC, the close approach of Mars in 2003, the 2018 Martian dust storm, the May 2024 coronal mass ejections reaching Earth, and sunrise at the lunar south pole. In the Explosion Lab a supernova, a gamma-ray burst or a solar eruption is set off anywhere from the Moon’s distance to 10,000 light years, and a model shows what it does to every body of the solar system, in the order the blast reaches them. Positions are checked against JPL Horizons; what is real and what is a model is labelled throughout.*

### B. AI Use Disclosure
- *In accordance with the 2026 NASA Space Apps rules, we disclose that AI coding assistants (Claude Code and others) were used for software architecture, TypeScript/Three.js/GLSL implementation, drafting of the Turkish and English content, the German, French, Spanish, Italian and Russian translations (machine-written, not reviewed by native speakers) and data-pipeline scripts. Celestial positions were checked against JPL Horizons DE441 tables in automated tests; terrain heights come from LOLA (Moon) and MOLA (Mars) data. Schematic visuals and models (sub-resolution craters, dust-storm spread, remnant shapes, descent trajectory, the path of Ingenuity’s flight between its recorded figures, the Explosion Lab, the ground on Mercury, Venus and Earth) are labelled as models. No NASA logos or insignia are used.*
